# Portafolio Personal - Alejandro Burciaga Calzadillas

Sitio web personal tipo CV/Portafolio desarrollado con HTML, CSS y JavaScript vanilla.

## Vista previa

Este portafolio incluye las siguientes secciones:

- **Inicio**: Presentación con animaciones y efecto de máquina de escribir
- **Sobre Mí**: Información personal y estadísticas
- **Habilidades**: Stack tecnológico con barras de progreso animadas
- **Proyectos**: Galería de proyectos con filtros por categoría
- **Experiencia**: Timeline de trayectoria académica y profesional
- **Contacto**: Formulario de contacto e información de contacto

## Tecnologías utilizadas

- HTML5
- CSS3 (Variables CSS, Flexbox, Grid, Animaciones)
- JavaScript (ES6+)
- Font Awesome (iconos)
- Google Fonts (Inter, Fira Code)

## Características

- Diseño responsivo (mobile-first)
- Tema claro/oscuro
- Animaciones suaves y transiciones
- Cursor personalizado
- Efecto parallax
- Filtros de proyectos
- Contador animado de estadísticas
